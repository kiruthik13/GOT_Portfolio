## 🐉 The Cinematic Experience

This portfolio is not just a collection of links, but an immersive journey through the digital Seven Kingdoms:

*   **Sword Energy Waves**: A custom Canvas-based hero animation featuring magical golden radiation and amber sparks.
*   **The Forging Screen**: A thematic loading sequence with runic messages and an animated forged sword.
*   **Royal Herald AI**: An interactive chatbot persona that speaks in the tongue of the realm, integrated with LLM-style logic.
*   **Chronicle of Conquests**: A dynamic projects showcase with custom mockups and "House" themed skill cards.
*   **The Sacred Parchment**: A beautifully rendered resume section and GitHub stats integration.
*   **Atmospheric Ambient**: Integrated Web Audio API for a subtle, toggleable fantasy soundscape.

## 🛠 Tech Stack

*   **Frontend**: React.js 18
*   **Build Tool**: Vite
*   **Styling**: Pure Vanilla CSS (No UI libraries used for maximum design fidelity)
*   **Graphics**: Canvas API (Fire, Energy Waves, Particles)
*   **Audio**: Web Audio API
*   **Integration**: GitHub API v3

## 🏰 Installation

1.  **Clone the Repository**
    ```bash
    git clone https://github.com/Kiruthikbairavan/portfolio-of-the-realm.git
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Run the Realm**
    ```bash
    npm run dev
    ```

## 🏰 Project Structure

```text
├── frontend/ (Current src)
└── backend/
    ├── server.js      # Entry point
    ├── config/db.js   # MongoDB Connection
    ├── models/        # Database Schemas
    └── routes/        # API Endpoints (Contact/Ravens)
```

## ⚔ Backend Setup

1.  **Navigate to Backend**
    ```bash
    cd backend
    ```

2.  **Configure .env**
    The `.env` file is already created with your provided URI and Resend key.

3.  **Run Backend**
    ```bash
    npm run dev
    ```
    The Citadel will be listening at `http://localhost:5000`.
